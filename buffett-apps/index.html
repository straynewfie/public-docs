Buffett Apps

Buffett Apps is a shared sign-in identity used by participating independently named applications. It is not a separate game or a replacement for each application's own privacy policy.

Applications using this sign-in may offer Google authentication and email sign-in through Supabase. Each application has its own features, data practices, and applicable policies.
